# KOKTON
KOKTON | شركة كوكـتون  KOKTON شركة متعددة المجالات، تسعى إلى بناء مستقبل مبتكر من خلال التكنولوجيا والتطبيقات والألعاب الرقمية والحلول الذكية. نؤمن بالإبداع والتطوير المستمر، ونعمل على تحويل الأفكار الطموحة إلى مشاريع ومنتجات تواكب التطور العالمي، برؤية مستقبلية تجمع بين الابتكار والجودة والطموح.  KOKTON – نصنع المستقبل ونفتح آفاقاً جديدة.
